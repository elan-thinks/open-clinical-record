# Internship Overview

## Purpose

This document records the internship context and the industrial experience that surrounded the development of Open Clinical Record (OCR). It is a source-of-truth document for the final Industrial Practice Report.

## Organization

**Infinity Advanced Technology Solutions PLC**  
Addis Ababa, Ethiopia

## Internship Period

**01 September 2026 – 30 September 2026**

The first formal interaction with the organization was an interview with HR representative **Ms. Mahilet**. This interview marked the beginning of the intern's organizational engagement before the technical project work proceeded.

## Internship Project

**Open Clinical Record (OCR)** — a focused outpatient Electronic Medical Record (EMR) internship project.

The repository documentation identifies the implemented MVP around three core business areas:

1. Patient Management
2. Patient Chart
3. Appointment Management

The project was deliberately kept smaller than a full hospital EMR. Existing project documentation explicitly excludes pharmacy, laboratory, radiology, billing, patient portal, FHIR exchange, multi-facility enterprise scheduling, and AI clinical decision support from the MVP.

**Evidence:** `docs/03-requirements/srs/SRS.md`, `docs/08-finalization/technical-documentation.md`

## Internship Objective

The original internship objective was to experience a complete software development lifecycle through the design and development of a simplified EMR application. The planned lifecycle included requirements gathering, analysis, design, implementation, testing, documentation, and presentation, with mentor guidance and exposure to existing EMR systems.

## Reporting Timeline

The internship had **four weeks, with two tasks in each week**:

| Internship week | Task 1 | Task 2 |
|---|---|---|
| **Week 1** | Project Initiation, Requirement Analysis & Design | Project Foundation |
| **Week 2** | Patient Management Module | Medical Records Module |
| **Week 3** | Appointment & Consultation Module | Additional Features & Enhancements |
| **Week 4** | Testing, Bug Fixing & Refactoring | Finalization & Presentation |

This structure reflects the original internship plan. It should not be converted into an eight-week internship timeline.

## Industrial Context

The internship combined individual project work with exposure to an active development organization. Project work was carried out primarily through the OCR repository and development environment, while regular Wednesday in-person sessions provided exposure to organizational communication, project management, team coordination, and developer work.

## Core Learning Context

A major learning outcome was the practical value of documentation before implementation. Working through research, requirements, domain rules, architecture, data design, and other technical documentation before writing substantial code made the implementation process more understandable and reduced uncertainty.

The project also demonstrated the importance of scope management. The initial planned functionality was broader than could realistically be completed within the available internship period. Mentor feedback redirected the project toward the three core workflows. This allowed effort to be concentrated on a coherent MVP rather than spreading implementation across too many partially completed modules.
