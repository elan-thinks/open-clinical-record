## Scope Adjustment

The original plan was broader than the available project period. Mentor guidance narrowed the core target to:

1. Patient Management
2. Patient Chart
3. Appointment Management

The final repository documentation confirms that these three areas form the implemented MVP.

## Important Reporting Rule

The table above is a reconstruction from project documentation and firsthand internship information. Where a specific activity needs exact chronological proof, the final report should use Git history, issue history, dated documents, meeting records, or other available evidence rather than inventing dates.

## Main Difference Between Plan and Actual Work

The most important difference was not that the project abandoned its original purpose. Instead, the scope was deliberately concentrated so that the core clinical workflow could be completed as a coherent MVP.

This resulted in a practical progression:

**Broad EMR plan → mentor scope review → focused three-module MVP → implementation → testing/refinement → final documentation and presentation.**
