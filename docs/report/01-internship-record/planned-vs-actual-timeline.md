# Planned vs Actual Internship Timeline

This timeline preserves the **original four-week internship plan exactly as structured by the internship document: four weeks, with two tasks in each week**. It must not be presented as an eight-week internship or as eight separate internship weeks.

|---|---|---|---|

## Scope Adjustment

The original plan was broader than the available project period. Mentor guidance narrowed the core target to:

1. Patient Management
2. Patient Chart
3. Appointment Management

The final repository documentation confirms that these three areas form the implemented MVP.

## Important Reporting Rule

The table above is a reconstruction of the **four-week internship plan**, not a claim that the internship lasted eight weeks. Tasks are shown separately because the original plan explicitly divided each of the four weeks into Task 1 and Task 2.

Where a specific activity needs exact chronological proof, the final report should use Git history, issue history, dated documents, meeting records, or other available evidence rather than inventing dates.

## Main Difference Between Plan and Actual Work

The most important difference was not that the project abandoned its original purpose. Instead, the scope was deliberately concentrated so that the core clinical workflow could be completed as a coherent MVP.

The correct reporting structure is:

**4-week internship → Week 1 (Task 1 + Task 2) → Week 2 (Task 1 + Task 2) → Week 3 (Task 1 + Task 2) → Week 4 (Task 1 + Task 2) → implementation/testing/finalization evidence.**
