## Evidence Rules for the Final Report

### 1. Planned is not implemented

The original internship plan must not be used as proof that every planned feature was implemented.

### 2. Designed is not implemented

Requirements and architecture documents show what was specified/designed. Source code and testing evidence are required when claiming implementation.

### 3. Observed is not performed

Workplace observations should be described as observations unless the intern personally performed the activity.

### 4. Research is not product functionality

Research into Oracle Health, OpenMRS, Epic, WHO, FHIR, or other systems demonstrates investigation and learning. It does not mean OCR implemented the researched capabilities.

### 5. Final documentation is the implementation baseline

The final SRS and technical documentation should be used together with source code and tests when describing the final MVP.
