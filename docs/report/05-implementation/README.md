## Reporting Standard

Phase 05 follows an evidence-first rule. Implemented behavior is described separately from planned or future functionality. Each major visual claim has a specific screenshot instruction identifying what to capture, what must be visible, what must be hidden, and why the figure belongs at that exact point in the report.

Use synthetic/demo data in application screenshots. Never expose real patient information, credentials, JWTs, connection strings, or secret keys.

The chapter should be read together with Phase 03 (requirements/domain analysis), Phase 04 (system engineering), and Phase 06 (quality assurance).
